# 后台管理-知识库设计文档

## 1. 文档范围

本文定义 Web 管理后台复刻 WeKnora 知识库管理体验的页面、流程和权限边界。

后台的目标能力包括组织知识库列表、创建、基础配置、文件/URL/Markdown 导入、文档处理状态、文档预览下载、文件夹、标签、FAQ、Wiki、Graph 入口、项目关联和知识库审计。

当前第一方页面已接入列表、创建 `document`/`faq`/`wiki`、基础配置、Markdown/URL/文件导入入口、异步操作状态、文档重解析/删除和删除影响确认；服务端夹具另有文档详情、预览和下载路由，但页面尚未接入对应控件。FAQ、Wiki、图谱、项目和审计目前只有按类型显示的页签或入口。当前没有文件夹 CRUD、标签 CRUD、FAQ 条目编辑器、Wiki 页面编辑器、真实图谱数据、项目关联操作或知识库审计数据。

正文、Chunk、向量、BM25/RRF、Embedding、Rerank、异步解析和 WeKnora 原生租户数据仍由 WeKnora 持有；后台通过平台服务 API 代理，不直接访问 WeKnora 数据库、内部 Go 包或用户凭据。

插件会话检索行为见 [插件-知识库设计文档](https://github.com/STXR-1116/AI-coding-plugin/blob/main/docs/%E6%8F%92%E4%BB%B6-%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.md)，平台 API 和数据模型见 [服务API-知识库需求文档](服务API-知识库需求文档.md)。

## 2. 导航与页面结构

后台增加独立一级菜单“知识库”。项目详情的“资产关联”页可以筛选和关联知识库；知识库详情的“项目”页显示当前组织中使用该知识库的项目。

生产目标路由如下：

```text
知识库
  ├─ 知识库列表                    /knowledge-bases
  └─ 知识库详情                    /knowledge-bases/{knowledge_base_id}
       ├─ 概览                     ?tab=overview
       ├─ 文档                     ?tab=documents
       ├─ FAQ                      ?tab=faq      (仅 faq)
       ├─ Wiki                     ?tab=wiki     (仅 wiki)
       ├─ 图谱                     ?tab=graph    (wiki 或启用图谱)
       ├─ 设置                     ?tab=settings
       ├─ 项目                     ?tab=projects
       └─ 审计                     ?tab=audit
```

生产页面复刻 WeKnora 原生的列表卡片、详情标题栏、文档网格/列表切换、文件夹树、标签过滤、批量操作和处理状态展示，但通过平台稳定 DTO 实现，不使用 iframe 或透传 WeKnora 页面。当前联调页面只实现列表、详情、文档导入、重解析、删除和操作状态展示。

WeKnora 高级存储、VLM、部署专属索引和其他平台不支持的字段在设置页显示只读摘要与“打开 WeKnora”入口。入口使用服务端返回的管理 URL，不拼接 Token，不把外部凭据传入浏览器。

当前联调页面只使用 `/knowledge-bases` 页面和页面内页签，未实现 `/knowledge-bases/{knowledge_base_id}` 稳定详情路由或通过 URL 保存页签状态。

## 3. 访问守卫与角色矩阵

后台使用现有 HttpOnly Session 和服务端 API 代理。页面读取、组织切换、详情请求和每次写入都重新校验账号状态、角色、组织范围、项目状态、知识库状态和外部可用性。

前端控件只按固定角色矩阵显示，不读取或信任 `allowed_actions`；隐藏控件不替代服务端鉴权。`member` 隐藏知识库管理菜单，直接访问路由或接口返回无数据的 `404` 或明确 `403`。

| 能力 | admin | manager | member |
|---|---:|---:|---:|
| 组织连接、租户映射和密钥轮换 | 是 | 否 | 否 |
| 查看组织知识库列表和详情 | 全平台 | 已加入的有效组织 | 否 |
| 创建、编辑基础配置 | 全平台 | 其组织/项目范围 | 否 |
| 导入文件、URL、Markdown | 全平台 | 其组织/项目范围 | 否 |
| 文档、文件夹、标签、FAQ、Wiki 管理 | 全平台 | 其组织/项目范围 | 否 |
| 关联/解除项目知识库 | 全平台 | 其组织/项目范围 | 否 |
| 删除外部 WeKnora KB | 全平台 | 其组织/项目范围，二次确认影响项目 | 否 |
| 查看知识库审计 | 全平台 | 其组织/项目范围 | 否 |

`manager` 的范围来自其加入的有效组织；后台不要求 manager 额外加入某个项目才能治理组织级知识库，但将知识库关联到项目时仍需校验目标项目组织和项目状态。

上表是生产服务的授权目标；本地页面和内存服务只覆盖已实现的列表、基础配置、文档导入/处理、文档删除和删除影响流程。

## 4. 知识库列表

列表默认显示当前治理范围内的 `active` 和 `unavailable` 知识库；`deleting` 和外部已删除状态通过明确状态筛选读取。页面支持组织、类型、处理状态、可用性、名称关键字和游标分页，使用服务端稳定排序。

列表卡片或表格至少显示名称、类型、描述摘要、文档数、Chunk 数、处理状态、Embedding/摘要模型、关联项目数、更新时间和平台 `revision`。不显示 WeKnora 租户 ID、外部 `kb_id`、Token、完整正文或隐藏组织/项目数量。

创建入口打开按 WeKnora 原生顺序组织的表单：名称、描述、类型（`document`/`faq`/`wiki`）、Embedding 模型、摘要模型和平台支持的基础处理选项。模型和能力选项从服务端动态读取，提交时服务端再次校验。

创建请求完成外部 KB 创建后才显示成功；处理状态或连接不可用时显示操作资源和错误，不把本地草稿当作 WeKnora 创建成功。创建后的知识库在组织级存在，项目关联是独立动作。

## 5. 知识库详情

### 5.1 概览

概览显示名称、描述、类型、处理状态、模型、文档/Chunk 计数、最近操作、关联项目摘要、外部可用性和更新时间。`unavailable` 显示外部错误摘要、最近确认时间和重新检查按钮，不用过期快照冒充实时成功。

### 5.2 文档

生产文档页复刻 WeKnora 的网格/列表视图和文件夹树，支持标题/文件名搜索、类型过滤、标签过滤、文件夹进入、文档详情、预览和下载。当前联调页仅显示文档列表和重解析/删除按钮，没有网格/列表切换、文件夹树、搜索过滤、预览或下载控件。

导入菜单提供文件、URL 和手工 Markdown 三种入口。批量文件按文件逐个创建文档资源，目录相对路径映射为 WeKnora 文件夹；每项返回独立操作状态，不因同批其他文件成功而隐藏失败。

文档状态按 WeKnora 处理状态展示：`pending`、`processing`、`finalizing`、`completed`、`failed`、`deleting`、`cancelled`。后台通过操作资源轮询或已有事件刷新；只有确认外部完成后才显示完成。

文档工具栏支持重解析、删除、移动文件夹、添加/移除标签和批量选择。重解析、删除和批量处理均使用独立幂等操作；失败保留错误摘要和重试入口，不能静默回滚为成功。

### 5.3 FAQ、Wiki 和图谱

生产页面中，`faq` 知识库显示问答条目列表、创建、编辑、删除、标签和处理状态；不把 FAQ 条目强行转换为普通文档。当前 FAQ 页签只显示服务端管理说明，没有条目 CRUD。

生产页面中，`wiki` 知识库显示页面树、页面编辑、预览、关联页面和图谱入口；启用图谱的知识库显示节点/关系查询和来源引用。当前 Wiki 页签只显示服务端管理说明，图谱请求返回空节点和关系集合，没有真实页面或图谱数据。

类型不支持的页签不显示。服务端仍拒绝直接调用不匹配类型的接口并返回 `422 VALIDATION_ERROR`，前端隐藏不是安全措施。

### 5.4 设置

设置页提供名称、描述、类型不可变字段、Embedding/摘要模型和平台支持的基础解析/分块配置。复杂存储、VLM、部署专属向量引擎和 WeKnora 版本相关选项显示只读摘要，并提供外部管理入口。

配置更新成功后以服务端响应替换表单，处理中的知识库显示配置锁定或明确的冲突提示。每次更新必须携带 `If-Match`/`expected_revision` 和 `Idempotency-Key`。

### 5.5 项目

生产项目页显示组织内关联该知识库的项目、项目状态、映射状态、关联时间和最近操作者，并支持关联或解除单个项目；解除只删除平台映射，不删除 WeKnora KB。当前项目页只有服务端校验说明，没有关联/解除控件或真实项目映射列表。

只能将知识库关联到同组织的 `draft` 或 `active` 项目；归档项目的映射只读。active 项目可被插件检索，draft 项目可用于上线前准备。

### 5.6 审计

生产审计页显示创建、配置更新、导入、重解析、文档删除、标签/文件夹/FAQ/Wiki 变更、项目关联/解除、外部删除、权限拒绝、修订冲突和 WeKnora 失败，并支持时间范围、操作者、动作、结果和游标筛选。当前审计页只有说明文本，内存服务返回空集合，没有上述事件字段。

## 6. 删除与不可用状态

“从项目移除”和“删除知识库”是两个不同动作。移除只解除当前项目映射；删除会调用 WeKnora 删除外部 KB，并在确认后影响所有项目映射。

删除按钮先读取影响项目和当前 revision，二次确认必须明确外部删除不可恢复、受影响项目数量和项目名称。确认请求携带影响快照、当前 revision 和幂等键；外部删除进入 `deleting` 操作。

确认外部删除完成后，知识库资源和所有项目映射转为 `unavailable`/`unlinked`，插件立即停止检索。平台不得按名称自动创建替代 KB，不提供恢复、迁移或静默解绑。

WeKnora 返回 404 时保留平台映射、标记 `unavailable` 并保留审计；后台提供重新绑定已有 KB、解除映射和重新检查入口。连接 5xx、超时和模型不可用同样显示 unavailable，不显示旧成功数据。

## 7. 写入和错误语义

所有创建、更新、导入、重解析、项目关联/解除和删除请求都必须带 `Idempotency-Key` 与 `If-Match` 或 `expected_revision`。相同键和相同请求重放第一次响应；相同键提交不同请求返回 `409 IDEMPOTENCY_CONFLICT`。

过期 revision 返回 `409 REVISION_CONFLICT`；外部依赖不可用返回 `503 SERVICE_UNAVAILABLE`；资源不存在或不可见返回 `404`；可见但无权操作返回 `403`；字段或类型不支持返回 `422 VALIDATION_ERROR`。

后台只在服务端明确成功后显示成功提示并刷新详情。网络中断、超时、冲突和外部失败均显示失败或处理中状态，不能从表单当前值推断保存成功。

## 8. 验收场景

- admin 创建三种类型知识库并查看列表、详情、模型和状态；manager 只能操作其组织范围；member 菜单隐藏且直接访问无数据。
- 文件、URL、Markdown 导入均返回真实异步状态；单个失败不被批量成功掩盖，可查看错误并重试。
- 文档网格/列表、文件夹、标签、预览、下载、重解析和删除行为与 WeKnora 原生接口语义一致。
- FAQ、Wiki、Graph 按类型显示对应页面，类型不匹配请求返回 `422`。
- 项目关联和解除独立于外部 KB 删除；归档项目映射只读；跨项目复用时删除显示全部影响项目。
- WeKnora 404/5xx、连接超时、修订冲突和幂等冲突均不显示本地成功，映射进入可诊断的 unavailable 状态。
- 页面、接口和日志不暴露 WeKnora 外部资源 ID、Token、租户凭据、完整请求内容或完整知识正文副本。
